# 🎮 منصة الشايب للألعاب التفاعلية (AL-SHAIB Interactive Games Platform)

منصة ألعاب تفاعلية وبث مباشر متكاملة مصممة للبثوث المباشرة على **TikTok LIVE** ومنصات البث الأخرى، مبنية باستخدام **Next.js 15** و **Tailwind CSS**.

---

## 🕹️ الألعاب المتضمنة في المنصة

1. **🚌 باص الطيبين (Bus Tayyibin)**:
   - لعبة (ولد، بنت، حيوان، نبات، جماد، بلاد) التفاعلية عبر تعليقات البث.
   - استقبال كلمة «العب» لدخول اللاعبين تلقائياً.
   - كشف الحروف بنظام عجلة الحظ (Slot Machine).
   - لوحة تحكم للكنترول والمضيف لاعتماد أو رفض الإجابات وتصفير النقاط فوراً.
   - تتويج الفائزين ومنصة التتويج (Podium).

2. **🎯 روليت الصياد (Hunter Roulette)**:
   - لعبة البقاء والإقصاء للمباشر.
   - ترقيم الضحايا بشارات ذهبية عالية الوضوح `#1, #2, ...`.
   - اصطياد الضحية عبر كتابة رقمها في الشات أو بالضغط المباشر.
   - ميكانيكية «بوابة الإحياء النادرة» (Rare Revive Gate) لإعادة لاعب مستبعد للمنافسة.
   - قائمة مفصولة للمستبعدين.

3. **🪑 الكراسي الموسيقية (Musical Chairs)**:
   - محاكاة للكراسي الموسيقية تفاعلياً مع المشاهدين.

4. **💣 تمرير القنبلة (Bomb Pass)**:
   - لعبة التوتر والسرعة لتمرير القنبلة قبل الانفجار.

5. **🔢 تخمين الأرقام وسرعة البديهة (React Game)**:
   - تخمين الرقم السري وسرعة الرد مع عداد القلوب.

6. **🧩 تطابق الذاكرة (Memory Match)**:
   - كشف البطاقات المتطابقة في البث.

7. **🔤 الكلمات المختلطة (Mixed Words)**:
   - فك وتجميع الحروف المشوشة.

8. **🔐 لعبة الخزنة (Vault Game)**:
   - كسر الرمز السري للخزنة.

9. **💬 وش يقولون**:
   - مسابقة تخمين الإجابات الأكثر شعبية.

10. **🇸🇦 ألعاب وتحديات اليوم الوطني**:
    - خريطة المملكة، الفعاليات التفاعلية، وبنك الأسئلة الوطنية.

---

## 🚀 التشغيل المحلي (Local Development)

```bash
# تثبيت الحزم
pnpm install

# تشغيل المنصة في بيئة التطوير
pnpm dev
```
افتح المتصفح على: `http://localhost:3020`

## ☁️ الرفع على Vercel (استضافة مجانية دائمة)
